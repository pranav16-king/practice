🤖 LunaBot

A ROS-powered robotic platform designed for autonomous navigation, mapping, and habitat monitoring on the Moon—supporting the next era of lunar exploration.

Get Started

Background

Sustained lunar presence demands robotic systems that can autonomously handle navigation and maintenance tasks. Without GPS and amidst harsh environments, LunaBot provides a dependable solution for continuous habitat operations and safety assurance. Powered by ROS, it leverages a modular software framework ideal for real-time navigation and intelligent decision-making.

Core Features

Autonomous Navigation

Navigate lunar habitats using LiDAR, cameras, and IMU sensor fusion for precise localization.

Obstacle Detection

Detect hazards and plan safe routes to ensure mission reliability in harsh and dynamic lunar conditions.

Habitat Monitoring

Monitor temperature, oxygen levels, and other critical environmental parameters continuously.

System Architecture

  • Perception Layer: LiDAR, stereo cameras, and IMU sensors for real-time mapping and localization.
  • Planning Layer: ROS-based path planning and obstacle avoidance using sensor fusion data.
  • Control Layer: Motion control algorithms for smooth, energy-efficient mobility across rugged terrain.
  • Monitoring Layer: Continuous habitat environmental checks with automated alert mechanisms.

Expected Deliverables

  • ROS packages implementing navigation, mapping, and maintenance monitoring.
  • Simulation scenarios validating lunar habitat operations with anomaly detection.
  • A demonstration video showcasing autonomous patrols and environmental monitoring.
